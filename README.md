# SerwaDron - Profesjonalne Usługi Dronowe

Witaj w portfolio SerwaDron! To nowoczesna aplikacja webowa zbudowana w celu prezentacji profesjonalnych usług z zakresu filmowania i fotografii lotniczej. Projekt został stworzony z myślą o wysokiej wydajności, estetyce oraz funkcjonalności biznesowej.

## 🚀 Technologie
Projekt został zbudowany przy użyciu nowoczesnego stosu technologicznego:

* **Framework**: [Next.js 16](https://nextjs.org/) (z użyciem App Router)
* **Kompilator**: [Turbopack](https://nextjs.org/blog/turbopack)
* **Stylizacja**: [Tailwind CSS](https://tailwindcss.com/)
* **Komponenty UI**: [shadcn/ui](https://ui.shadcn.com/)
* **Animacje**: [Framer Motion](https://www.framer.com/)
* **Wysyłka maili**: [Resend](https://resend.com/)
* **Wdrożenie**: [Vercel](https://vercel.com/)

## ✨ Kluczowe funkcje
* **Interaktywna prezentacja**: Płynne animacje sekcji portfolio oparte na Framer Motion.
* **Modal wideo**: Możliwość podglądu realizacji wideo w trybie pełnoekranowym.
* **Formularz kontaktowy**: Zintegrowany system przesyłania zapytań ofertowych bezpośrednio na e-mail za pośrednictwem API Resend.
* **Responsive Design**: W pełni responsywny interfejs dostosowany do urządzeń mobilnych i desktopów.
* **Wydajność**: Optymalizacja pod kątem szybkości działania dzięki Next.js.
